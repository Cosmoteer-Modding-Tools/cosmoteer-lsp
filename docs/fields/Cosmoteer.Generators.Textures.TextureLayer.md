## Name

The opacity of this layer.

## BlendMode
`enum TextureLayerBlendMode` · optional · one of: `AlphaBlend`, `Add`, `Subtract`, `Multiply`, `Replace`, `Min`, `Max`

Specifies how this layer will be applied to the previous layer's results.

## ColorScale
`Color` · optional

The per-channel color scaling applied to this layer's color before it is blended onto the previous layer's results.

## ReadClippingMask
`bool` · optional

If true, the effects of this layer will be clipped to the alpha channel of the previous layer that has this set to false.

## WriteClippingMask
`bool` · optional

If true, this layer's alpha values will be written to the clipping mask.

## WriteTexture
`bool` · optional

If true, this layer will write to the texture.

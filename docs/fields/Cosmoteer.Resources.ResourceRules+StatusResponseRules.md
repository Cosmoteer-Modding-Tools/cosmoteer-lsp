## StatusTriggers
`StatusTriggerData[]` · optional

The statuses that set off the response. Without this list the response reads a single trigger from its own group, so `StatusType` and `ValueRange` can be written directly beside the effects, which is how vanilla writes it. A response with neither fails to load. Only the first trigger for a given status is checked, so a second trigger for the same status never fires. The response runs on each storage tile that holds this resource whenever that status changes on the tile.

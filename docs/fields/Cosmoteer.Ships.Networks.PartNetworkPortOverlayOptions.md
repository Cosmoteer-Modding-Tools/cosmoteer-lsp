## OverlayIcon
`→ PartNetworkOverlayIcon` · optional

The ID of the custom overlay icon drawn to represent the port.

## ConnectedEdgeIcon
`→ PartNetworkOverlayIcon` · optional

The ID of the additional icon to draw on the port's edge when connected, if any.

## RouteLine
`→ BasePartNetworkRouteLine` · optional

The ID of the custom overlay route line drawn for the port's routes.

## DrawRouteHub
`bool` · optional · default `true`

Whether this port wants its component to draw a 'route hub' sprite. A hub will be drawn if this is true for any connected ports.

## RouteDrawMode
`enum PartNetworkPortOverlayRouteDrawMode` · optional · default `Always` · one of: `Never`, `Connected`, `Always`

The mode determining when route lines should be drawn for the port.

## IconDrawMode
`enum PartNetworkPortOverlayIconDrawMode` · optional · default `Always` · one of: `Never`, `Primary`, `CanConnect`, `Always`

The mode determining when the icon should be drawn for the port

## HighlightPartOnPrimaryConnection
`bool` · optional · default `false`

Whether the port's part will be highlighted when connected to a port on a part being placed.

## PartHighlightColor
`Color` · optional

The color of the highlight drawn when HighlightPartOnPrimaryConnection is true.

## SpreadHighlightThroughNetwork
`→ PartComponentRules` · optional

The ID of a network node provider component that the highlight should spread from to all parts in its network, if any.

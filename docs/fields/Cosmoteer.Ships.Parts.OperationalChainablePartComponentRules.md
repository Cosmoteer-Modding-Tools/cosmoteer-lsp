## OperationalToggle
`→ PartComponentRules` · optional

A toggle component on the same part that gates whether this component operates. The component is operational only while the part is active and the toggle reads on. When unset, the component operates whenever the part is active. Behaves exactly like [[Cosmoteer.Ships.Parts.OperationalPartComponentRules.OperationalToggle]], on a component that can also be chained.

## InvertOperationalToggle
`bool` · optional

Reverses the reading of [[Cosmoteer.Ships.Parts.OperationalChainablePartComponentRules.OperationalToggle]], so the component operates while the toggle is off and shuts down while it is on.

## DisableWhenDeconstructing
`bool` · optional

Makes the component non-operational while its part is queued for deconstruction. It resumes operating if the deconstruction order is cancelled.

## Enabled
`bool` · optional

Whether this WidgetSpriteUVManager will adjust the given WidgetSingleSprite's UVRect. Set this to false to not modify its UVRect.

## BaseUVRect

The UVRect that will be used when the entire sprite should be displayed.

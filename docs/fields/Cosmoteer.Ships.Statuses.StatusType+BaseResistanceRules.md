## DivideByPartArea
`bool` · optional

Whether to divide the resistance value by the tile-area of the part.

## MultiplyByStatusCount
`bool` · optional · default `true`

Whether to multiply the resistance value by the instance count of this status type on the part. If this is false, this resistance is applied once, regardless of status count.

## ModificationMode
`enum SimpleValueModificationMode` · optional · default `Add` · one of: `Replace`, `Add`, `Subtract`, `Multiply`, `Divide`

How the resistance value from this rule is folded into the part's existing resistance. `Add` and `Subtract` shift it, `Multiply` and `Divide` scale it, and `Replace` discards the part's own value.

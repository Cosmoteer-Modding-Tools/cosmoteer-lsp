## StatusType
`→ StatusType` · required

The status whose changes are checked. Vanilla ammo and missile parts use `cosmoteer.scorched`.

## ValueRange
`range<float>` · optional

The combined status value, inclusive at both ends, at which the response fires. Defaults to any value. Vanilla uses `[1,1]` so stored munitions explode only once their part is fully scorched.

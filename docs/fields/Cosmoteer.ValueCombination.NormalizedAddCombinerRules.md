## ValueRange
`range<float>` · optional

The range to use for lerp and inverse-lerp operations.

## InverseValueExponent
`float` · required

The exponent applied to (1-normalizedBaseValue) before multiplication with the normalizedOtherValue.

## ReducePositiveValues
`bool` · optional · default `true`

Whether positive input values should be reduced by the inverse value.

## ReduceNegativeValues
`bool` · optional · default `true`

Whether negative input values should be reduced by the inverse value.

## MinFactor
`float` · optional

Floor on the inverse-value reduction. The reduction factor is `pow(1 - normalizedBase * (1 - MinFactor), InverseValueExponent)`, so when the base value sits at the top of ValueRange the other value's contribution is retained at MinFactor rather than dropping to zero. Defaults to 0, allowing full reduction.

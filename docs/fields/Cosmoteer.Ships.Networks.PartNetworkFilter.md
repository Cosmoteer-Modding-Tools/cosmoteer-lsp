# Cosmoteer.Ships.Networks.PartNetworkFilter

Narrows a part-network search to components carrying one of the listed categories. Its `Categories` and `AllowUncategorized` fields are written directly on the searching component.

## Categories
`→ PartNetworkCategory[]` · optional

The network categories that components must match one or more of to be considered valid. If this is null, all categories will be allowed.

## AllowUncategorized
`bool` · optional

Whether components with no network categories will be included.

## Holdable
`bool` · optional

Whether the user can press and hold the key to generate repeated selection changes.

## HoldInitialRepeatInterval
`Time` · optional

The amount of time between the initial press of a key and the first repeated selection change. Has no effect if Holdable is false.

## HoldRepeatInterval
`Time` · optional

The amount of time between each selection change while the user is holding a key. Has no effect if Holdable is false.

## PrevKey
`enum ViKey[]` · optional

The IInputButton that can be pressed to move the caret to the previous text character.

## NextKey
`enum ViKey[]` · optional

The IInputButton that can be pressed to move the caret to the next text character.

## UpKey
`enum ViKey[]` · optional

The IInputButton that can be pressed to move the caret up one line of text.

## DownKey
`enum ViKey[]` · optional

The IInputButton that can be pressed to move the caret down one line of text.

## BeginKey
`enum ViKey[]` · optional

The IInputButton that can be pressed to move the caret to the beginning of the text.

## EndKey
`enum ViKey[]` · optional

The IInputButton that can be pressed to move the caret to the end of the text.

## SelectAllKey
`enum ViKey[]` · optional

The IInputButton that can be pressed to select all of the text.

## AppendSelectionKey
`enum ViKey[]` · optional

The IInputButton that can be held to append text to the selection instead of replacing the selection.

## DisableDuringImeTextComposition
`bool` · optional

Whether text selection will be disabled while the OS input method editor is composing text.

## Color
`IntColor` · required

The color that will be applied to the font's edges.

## RelativeThickness
`float` · optional

The thickness of the stroke effect relative to the size of the font. This will be added with AbsoluteThickness.

## AbsoluteThickness
`float` · optional

The thickness of the stroke effect in pixels. This will be added with RelativeThickness.

## Falloff
`float` · optional

A number that indicates how quickly the stroke effect will disappear as the distance from the edge of the font increases.

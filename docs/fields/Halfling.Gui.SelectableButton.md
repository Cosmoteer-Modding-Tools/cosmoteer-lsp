## IsSelected
`bool` · optional

Whether this Widget is currently selected. Getting this property is a simple shortcut for SelectionController.IsSelected. Setting this property will call SelectionController.AttemptToSelect or AttemptToDeselect and throw an InvalidOperationException if the attempt fails.

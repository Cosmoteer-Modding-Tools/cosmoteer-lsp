## AutoWidthMode
`enum AutoSizeMode` · optional · one of: `Disable`, `Enable`, `CalculateOnly`

Whether the width of the widget is automatically sized to match its contents. The desired size of the contents is defined by the DesiredSizeProvider property.

## AutoHeightMode
`enum AutoSizeMode` · optional · one of: `Disable`, `Enable`, `CalculateOnly`

Whether the height of the widget is automatically sized to match its contents. The desired size of the contents is defined by the DesiredSizeProvider property.

## IgnoreForParentAutoSize
`bool` · optional

Whether the attached widget should be skipped when computing the desired size of its parent widget.
